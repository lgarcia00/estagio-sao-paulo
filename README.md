# 🚀 Teste Técnico – Estágio São Paulo

Este repositório contém as resoluções de 5 exercícios propostos para um processo seletivo de estágio. A linguagem escolhida foi **Dart**, destacando lógica, manipulação de dados e raciocínio computacional.

## 🧠 Exercícios Resolvidos

1. **Desafio dos interruptores e lâmpadas**  
   - Explicação lógica sobre como identificar qual interruptor acende qual lâmpada utilizando apenas duas visitas às salas.

2. **Verificador de número na sequência de Fibonacci**  
   - Recebe um número do usuário e determina se pertence à sequência de Fibonacci.

3. **Análise de faturamento com base em dados JSON**  
   - Calcula:
     - Menor valor de faturamento diário
     - Maior valor de faturamento diário
     - Número de dias com faturamento acima da média mensal

4. **Cálculo percentual de faturamento por estado**  
   - Recebe os dados de faturamento por estado e retorna o percentual de participação de cada um no total da distribuidora.

5. **Inversor manual de string**  
   - Transforma uma string em uma lista de caracteres, inverte os elementos manualmente utilizando `while`, e exibe o resultado final.

## Considerações:

Optei por utilizar Dart por ser uma linguagem moderna, com forte tipagem e estrutura clara, ideal para lógica e testes técnicos. Cada exercício foi implementado com foco em legibilidade, clareza e boas práticas.
